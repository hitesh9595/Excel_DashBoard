# Excel Sales Dashboard 

An interactive Sales Dashboard built in Microsoft Excel using Pivot Tables, Charts, Slicers, Conditional Formatting, and VBA Macros to analyze sales performance and business KPIs dynamically.

---

##  Features

- Interactive Dashboard
- Dynamic Filtering using Slicers
- KPI Tracking
- Sales Performance Analysis
- City-wise Sales Insights
- Target Hit Percentage Analysis
- Automated Functionality using VBA Macros
- Professional Data Visualization

---

##  Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- VBA Macros
